6. Time Saved and Reflection

Time Estimate

- **Time spent with AI:** 1–2 hours
- **Estimated time without AI:** More than 4 hours
- **Estimated time saved:** Potentially 2+ hours, based on my estimates. This is not an exact measurement.

My Reflection

Today, I learned how to use Cursor AI to refactor my Weather App from JavaScript to TypeScript.

The most valuable lesson for me was learning **how to write effective prompts**. I realized that giving AI clear instructions is important. A good prompt should include the project context, the task, the constraints, and the expected results.

During the process, my TypeScript build failed because the variable name `status` conflicted with the browser's global variable. I investigated the error and fixed it by renaming the variable to `statusMessage`. After that, the build completed successfully.

I also learned that I should not blindly trust AI-generated code. I need to review the changes, run the build, and test the application in the browser to make sure everything works correctly.

In the future, I want to use AI not only as a tool for generating code but also as an assistant that helps me think, debug problems, and learn new concepts. My goal is to become a better software engineer by understanding the code AI produces rather than simply copying it.
